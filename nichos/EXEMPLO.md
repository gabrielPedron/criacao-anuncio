# Nicho — [nome do nicho]

Copie este arquivo para `nichos/<seu-nicho>.md` e preencha só na sua máquina: o seu arquivo fica
fora do git, e este modelo não deve ser editado (editar arquivo do projeto trava o
`npm run atualizar`). Um arquivo por nicho. A `entrada.md` de cada produto diz qual usar.

Isto é **contexto** para o agente, não dado do produto: nada daqui entra na ficha ou na descrição
como afirmação sobre o produto sem a fonte do próprio produto (rótulo, ficha técnica, operador).
